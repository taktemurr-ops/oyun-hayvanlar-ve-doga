# Hayvanlar ve Doğa · Animals and Nature

Memeliler, kuşlar, böcekler: hayvanlar âlemini keşfet

Doğru hayvana dokun: hangisi memeli, hangisi yumurtlar, hangisi denizde yaşar, hangisi otla beslenir? Bacak sayısını bil, boyutları karşılaştır.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Bilgi Yarışması merkez uygulamasının oyunu; ortak motor: [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru).
